# 計算仕様

## 共通精度

- 金額: `roundMoney` で整数円へ四捨五入する。
- 数量: `roundQuantity` で小数第3位へ丸める。
- 金額一致: 丸め後の整数円で比較する。
- 数量一致: `0.001` 未満を許容差として比較する。
- 空欄はデータ上 `null`、計算上は0として扱い、画面では0と区別する。
- NaN、Infinity等の非有限値はエラーとする。

## 原材料・包装材料

酒種別・行別の当期使用額は次式とする。

```text
当期使用額 = 期首棚卸 + 当期発生 - 期末棚卸 + 振替・調整
```

振替・調整だけは負数を許容する。期末棚卸は製造原材料と包装材料に分けて棚卸資産へ集計する。

## 労務費・経費の配賦

対象酒種はマスターの `allocationEligible` が真の酒種に限る。対象外酒種は過年度在庫・工程・売上原価のデータを保持するが、共通費配賦額は0円とする。

```text
配賦対象額 = 費目総額 - 対象酒種の直課額合計
酒種別配賦額 = 直課額 + 配賦対象額の数量比または任意比率配賦
```

端数は最大剰余法を使い、同順位は固定酒種ID順で決める。有効状態では費目総額と酒種別配賦額合計が必ず一致する。個別入力方式は対象酒種の入力合計が費目総額と完全一致した場合だけ有効とする。

次をエラーとする。

- 配賦対象酒種が0件
- 配賦対象額があるのに数量または任意比率の合計が0
- 対象外酒種に直課額、任意比率、個別入力額がある
- 直課額合計が費目総額を超える
- 個別入力合計と費目総額が不一致
- 配賦後の内部差額が0円でない

## 副産物と当期製造原価

```text
副産物発生額 = 発生数量 × 評価単価
副産物期末棚卸 = 期末数量 × 期末単価
副産物売上原価 = 期首金額 + 発生額 + 購入金額 - 期末棚卸

酒種別当期製造原価
= 製造原材料使用額 + 製造労務費 + 製造経費 - 指定酒種の副産物発生額
```

副産物の品目名、購入金額、控除先酒種は入力可能とする。副産物売上原価が負ならエラーとする。

## 製品費用

```text
酒種別製品費用
= 包装材料使用額 + 製品労務費 + 製品経費 - 製品費用から控除する雑収入等
```

## 原酒

```text
払出数量 = 期首数量 + 当期製造数量 + 購入数量 - 期末数量 - 振替数量 - 欠減数量
払出金額 = 期首金額 + 当期製造原価 + 購入金額 - 期末金額 - 振替金額 - 欠減金額
単価 = 払出金額 ÷ 払出数量 × 1,000
```

## 詰口酒

```text
払出数量 = 期首数量 + 原酒からの受入数量 - 期末数量
払出金額 = 期首金額 + 原酒からの受入金額 - 期末金額 + 製品費用
単価 = 払出金額 ÷ 払出数量 × 1,000
```

工程上の詰口酒払出数量と、製品費用配賦基準の詰口数量の差は警告とする。

## 詰口製品

```text
売上原価数量 = 期首数量 + 詰口酒からの受入数量 - 期末数量 - 評価損・欠減数量
売上原価金額 = 期首金額 + 詰口酒からの受入金額 - 期末金額 - 評価損・欠減金額
単価 = 売上原価金額 ÷ 売上原価数量 × 1,000
```

原酒・詰口酒の払出数量／金額、詰口製品の売上原価数量／金額が負ならエラーとする。

## 甘酒

```text
当期原価 = 甘酒の当期製造原価 + 甘酒の製品費用
製造単価 = 当期原価 ÷ 当期製造数量
売上原価 = 期首金額 + 当期原価 - 期末金額
```

売上原価が負ならエラーとする。

## 食品

```text
当期食品製造原価
= 材料期首棚卸 + 材料仕入 - 材料期末棚卸 + 賃金 + 福利厚生費 + 外注費

食品原価未配賦差額 = 当期食品製造原価 - 食品別製造金額合計
食品別売上原価 = 期首金額 + 製造金額 - 期末金額
```

未配賦差額が0円でない場合、または食品別売上原価が負の場合はエラーとする。根拠のない自動配賦は行わない。

## 商品

```text
商品売上原価
= 期首商品棚卸 + 期首調整 + 当期仕入 + 酒税込仕入 + 未納税移出等
 - 仕入値引 - 他勘定振替 - 期末商品棚卸
```

負ならエラーとする。

## 棚卸資産と売上原価

```text
自製酒等期末棚卸高
= 原酒 + 詰口酒 + 詰口製品 + 甘酒 + 副産物 + 食品製品

期末棚卸資産合計
= 製造原材料 + 包装材料 + 自製酒等 + 食品材料 + 商品

売上原価合計
= 商品 + 自製酒類 + 甘酒 + 副産物 + 食品
```

## 年度確定

計算エラー0件、人による全確認のチェックとメモ、現行fingerprintに対する全警告のチェックと理由、確定担当者名を必須とする。確定後は入力、追加、名称変更、削除、貼付けをロックする。確定解除後も過去スナップショットは保持する。
