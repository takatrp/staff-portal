# Handwriting fonts

The unmodified Klee One Regular and Yomogi Regular font files are bundled in
`assets/hand-font-data.js` and loaded locally only when handwriting is requested.
Both fonts use the SIL Open Font License 1.1. Commercial use, embedding and
redistribution with the copyright notice and license are permitted under that
license. Font files must not be sold on their own.

- Klee One: Copyright 2020 The Klee Project Authors (https://github.com/fontworks-fonts/Klee)
- Yomogi: Copyright 2020 The Yomogi Project Authors (https://github.com/satsuyako/YomogiFont)

See `klee-OFL.txt`, `yomogi-OFL.txt`, and `hand-fonts.json` for the full licenses,
upstream source URLs, original sizes and SHA-256 hashes. PDF fonts are embedded
as subsets; image-only PDFs contain a rendered image with no selectable text.
No handwriting is copied from a real person's signature, and no seal is used.
