# 証憑デモ工房

架空の請求書・レシートをブラウザ内で生成する講演・研修用ツールです。

公開URL: https://takatrp.github.io/staff-portal/demo-voucher/

- PDF・ZIP・CSVをブラウザ内で生成。証憑データ・入力値の外部送信やサーバー保存なし。
- 20の架空発行者・独自ロゴ、請求書10様式・レシート10様式。
- 登録番号は全件T0000000000000（無効なダミー）。実事業者照会は対象外。
- 10%/軽減8%固定の研修シナリオ。実務・税率改正判定には使用しないでください。
- ZIP内の01_投入用にあるPDFだけを投入。照合用・全件見本は別フォルダ。
- 同じバージョン・条件・seedで再現可能。

このフォルダは公開可能な実行用静的ファイルのみを含みます。秘密情報・実顧客データ・口座情報・本物企業ロゴは含みません。

GitHub PagesのURLは、URLを知っている方なら閲覧可能です。ポータルの既存認証とは独立しています。

pdf-lib 1.17.1、fontkit 2.0.4互換バンドル、固定TTFからサブセット埋込するNoto Sans JPを使用。第三者ライセンスと資産ハッシュはlicenses/を参照。

## v1.1 ランダム生成

プレビュー横の「ランダム生成」で、表示中の証憑種類と設定した件数・日付・税率・内外税・端数方式を保ち、会社・様式・内容を切り替えます。処理中の連打は受け付けず、最後に表示したPDFと保存PDFを一致させます。seedは更新され、同じv1.1・条件・seedで会社と様式も再現できます。v1.0の条件JSONは同一結果を保証できないため読み込めません。

## アクセス計測

既存スタッフポータルの GA4（G-R4S7KNRPCP）で、本番の証憑デモ工房のページ表示を計測します。新しいプロパティは作成していません。集計時はページパス `/staff-portal/demo-voucher/` でスタッフポータル本体と区別してください。`index.html` で開いた場合もこのパスに統一します。

Google タグは、入力・証憑・ダウンロードリンクを持たない専用 iframe 内だけで動きます。生成画面の `connect-src 'none'` と `script-src 'self'` は維持しています。固定のページ URL・タイトルを使い、クエリ、ハッシュ、参照元、生成条件、seed、金額、PDF/CSV/ZIP、ファイル名を計測に渡しません。広告パーソナライズと Google シグナルも無効です。GA4 によるアクセス計測にはブラウザ・端末情報や計測用 Cookie が使われる場合があります。

`config` によるページビューを1回だけ使用し、手動の `page_view` は重ねません。ローカル開発や iframe の直接表示は計測せず、既存の GA オプトアウトと初期化前の同意コマンドを尊重します。GA4 側の拡張計測も空の iframe 内に限定され、生成画面の操作は計測対象にしません。

テスト: `node --test demo-voucher/tests/*.test.cjs`
